# E11 双估计头—分歧不确定性：锁定协议

## 数据边界

- 仅使用 `split=train` 的 2603 名开发集患者。
- 固定验证集与测试集均不得读取、训练、调参或评估。
- 使用 E10 已锁定的 10 个双重正交 Mass 表型。

## 模型

### H0：条件均值头

E8B Gaussian 规范模型与 Ridge 表型偏离预测，用于优化均方误差意义下的
条件均值。

### H1：稳健百分位头

E10-B 条件百分位规范化与 Group-DRO Ridge，用于优化 MAE、百分位偏离及
最坏亚群风险。

### H2：嵌套选择双头融合

\[
\hat y_{\lambda}=(1-\lambda)\hat y_{mean}+\lambda\hat y_{centile}
\]

- 候选权重：`0.0, 0.1, ..., 1.0`。
- 在每个外层训练折中再次执行 3 折交叉拟合，获得均值头和百分位头的
  内层 OOF 预测。
- 先筛选满足 `RMSE <= 均值头RMSE + 0.0005 mm` 的权重，再从中选择
  MAE 最低者。
- 若并列，选择更小的百分位头权重。
- 外层验证折只使用锁定后的权重一次，不参与权重选择。

## 分歧不确定性

\[
U_i=\frac{|\hat y_{mean,i}-\hat y_{centile,i}|}
{\hat\sigma_{age,sex,i}+\epsilon}
\]

验证：

1. `U` 与 H2 绝对误差的 Spearman 相关；
2. `U` 识别最高 20% 绝对误差病例的 AUROC；
3. 按低不确定性保留 100%、90%、80%、70% 样本后的 MAE；
4. 不使用 `U` 重新训练或校正预测。

## 重复验证

- 5 个预设随机种子；
- 每个种子 5 折患者级外层交叉验证；
- 每个外层训练折内 3 折权重选择；
- 各头内部的规范模型、表型残差化和 Ridge 超参数继续在训练折内完成。

## 主要判断标准

H2 作为最终连续读出必须同时满足：

1. 相对 H0 的患者级集成 MAE 差 95% CI 上界 `< 0`；
2. 相对 H0 的 RMSE 差 95% CI 上界 `<= 0.0005 mm`；
3. 至少 18/25 外层折 MAE 不劣于 H0；
4. 最坏年龄组、性别组和 CIMT 组 MAE 不高于 H0。

分歧不确定性只有满足下列条件才可作为可靠性指标：

1. 五种子平均 Spearman `rho(U, |error|) > 0.10`；
2. 高误差识别 AUROC `> 0.60`；
3. 从100%到70%覆盖率时平均 MAE总体下降，且不得出现超过
   `0.001 mm` 的反向恶化。

如果融合通过但分歧不确定性失败，保留双头融合，删除可靠性主张。
