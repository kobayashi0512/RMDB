# RMDB-C / BiMFO-Net：模型、实验、图表与论文叙事蓝图

## A. 一句话故事

**眼底不是用来“猜 CIMT”的普通图片；它是可重复、无创的微循环数字活检。我们以多尺度血管场而不是手工指标或黑箱像素，建立视网膜微循环到颈动脉壁重塑的跨器官映射。**

## B. 论文叙事（五幕）

### 第一幕：临床未满足需求

CIMT/斑块超声有价值但不适合所有人普筛；眼底检查低成本、双眼可重复、天然呈现微循环。但现有工作常把它降格为单次黑箱分类，且原始 CIMT 预测会受到年龄强混杂影响。

### 第二幕：概念转折

提出 RMDB：把眼底转化为标准化的微循环“数字活检”，而不是单病种图像分类。首个可证伪模块 RMDB-C 的目标是年龄性别条件下的 CIMT 加速（Delta-CIMT）。

### 第三幕：算法解法

提出 BiMFO-Net。它把血管编码为位置–方向–尺度–类别的微血管场，再通过跨尺度粗粒化和双眼共享/差异耦合映射到大血管壁重塑；全局基础模型特征只作补充。

### 第四幕：证据链

先证实测量层可信（血管、动静脉、视盘），再证实模型在年龄校正结局上优于手工表型和普通双眼图像模型；最后检验鲁棒性、校准、亚组和外部迁移。

### 第五幕：临床落点

输出并非单一风险分数，而是“微循环数字活检报告”：Delta-CIMT、加速风险、双眼共同/不对称信号、结构证据和不确定性；用途是超声前分诊，而非替代超声。

## C. 模型框架

```text
左/右 CFP
  ├─ 血管测量层：P(vessel), direction, local scale          ┐
  ├─ V1 多尺度血管场 F(x,y,theta,s) ─ field encoder ──┐     │
  └─ DINOv2 全局表征 ─ global projection ─────────────┼──┐  │
                                                       │  │  │
左/右场的质量门控共享–差异耦合 ──────────────────────┘  │  │
                                                          ├─ Delta-CIMT 回归 + 不确定性
年龄、性别（仅用于条件标签/条件约束）──────────────────────┤
                                                          └─ CIMT 加速风险

V2：以真实视盘直径坐标替代图像 FOV 坐标，并加入 A/V 类型维度 F(x,y,theta,s,t)。
```

## C.1 预处理创新：AAIU 解剖锚定标准化器

### 目标

不是让图像“更好看”，而是将每张图变成可比较的生物学测量，同时不把低质量、设备风格和病理外观混为一谈。

### 四步输出

1. **视野与质量测量**：FOV 覆盖、模糊、曝光、眩光、血管/地标置信度；低置信图进入拒识或复拍路径，而非强行增强。
2. **解剖规范化**：检测视盘和黄斑；将左右眼镜像为同一鼻侧–颞侧语义；把视盘–黄斑轴旋转至统一方向；V2 使用视盘直径作为空间尺度。
3. **保真双/三视图分解**：保留原始彩色图（病灶与颜色信息）、低频照明归一化的结构图、血管似然图。模型学习跨视图一致结构，而不以增强后的图取代原图。
4. **不确定性传播**：把质量和地标置信度作为门控/输出，而不是把失败的分割当作可信表型。

### 为什么是算法创新而不只是 preprocessing

- 规范化坐标使场 `F(x,y,theta,s,t)` 成为跨眼、跨设备、跨尺度可比较的对象；
- 左右眼不再仅按像素对齐，而是在共同解剖坐标中比较共同场与不对称场；
- 原始/结构/血管三视图防止对比增强抹掉颜色、出血或病灶信息；
- 质量门控使模型能够拒绝不可靠数字活检，形成临床安全边界；
- 所有步骤都可以逐项消融：无坐标规范化、无多视图、无质量门控、无风格扰动。

## D. 参数冻结表

完整可执行参数见 `configs/rmdb/bimfo_v1.yaml`。关键冻结项：

| 模块 | V1 固定值 | V2 升级 |
|---|---|---|
| 输入 | 双眼 512×512 CFP | 同左 |
| 血管场 | 12 方向 × 4 尺度 `[1.5,3,6,12]` px | 增加 A/V/交叉类别 |
| 坐标 | 图像 FOV 归一化 | 视盘直径归一化 Zone B/C |
| 全局表征 | DINOv2 ViT-S/14，前 5 epoch 冻结 | RETFound 对照或替换 |
| 场编码器 | 64/96/128 通道 | 同左 |
| 双眼模块 | 质量门控 shared/difference | 加入跨眼最优传输对齐 |
| 主标签 | 训练集年龄–性别样条残差 Delta-CIMT | 同左 |
| 训练 | 35 epoch、batch 4、AdamW 1e-4 | 预注册后可调参 |

## E. 实验任务流程

### P0：数据与标签冻结

- 审计 2,903 患者与 5,806 双眼图；患者级拆分；Group 3 测试集锁定。
- 仅在 Group 1 拟合年龄–性别 CIMT 期望模型；将该函数应用到验证/测试，得到 Delta-CIMT。
- 使用训练集 Delta-CIMT 第 75 百分位定义加速风险阈值；阈值不在验证或测试中重估。

### P1：测量层验证

- FIVES：二元血管 Dice、敏感性、特异性；已完成官方测试 Dice 0.8664。
- Fundus-DG-OD/OC：视盘/视杯 Dice、跨域性能、尺度误差。
- RITE：动脉、静脉、交叉 F1；仅在正式获权后进行。
- 对 CIMT 图像进行 20 张人工 QC，记录失败模式。
- 验证 AAIU：同一图像的旋转、缩放、亮度、JPEG 扰动前后，规范化坐标、血管场和风险输出应稳定；真实病灶不得被归一化消除。

### P2：传统比较基线

- 年龄+性别；
- 双眼 DINOv2；
- 全局手工血管表型；
- 视盘 ROI 手工表型；
- 普通双眼图像融合。

### P3：BiMFO V1

- 二元多尺度血管场；
- 双眼 shared/difference 耦合；
- Delta-CIMT 回归 + 加速风险联合学习；
- 选择模型只看 Group 2 验证集。

### P4：BiMFO V2 正式模型

- 接入真实视盘直径坐标、A/V 场和区域粗粒化；
- 全部消融；
- 与 P2/P3 在同一锁定验证集比较；
- 只有架构完全冻结后，运行一次 Group 3 测试。

### P5：可信度与临床验证

- 校准、置信区间、决策曲线、净获益、亚组与鲁棒性；
- 外部 CIMT 队列锁定评估；
- CFP+OCTA 子队列检验微血管场的生物学锚定。

## H. 结果判定规则

- 若 BiMFO 只提高原始 CIMT AUC、却不改善 Delta-CIMT 或校准：不能宣称跨器官微血管信号成功。
- 若测量层在 CIMT 图像 QC 不可靠：先修复测量/域适应，不进入 V2。
- 若 V1 在验证集无增益：报告阴性结果，分析哪一尺度/方向信息失效，不能以测试集调参。
- 若 V2 对 Delta-CIMT、校准、决策净获益至少一项有稳定提升，并在外部队列保持：可支撑 RMDB-C 首个模块的主张。
