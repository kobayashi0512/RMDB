# BiMFO / RMDB 已知问题审计与修复记录

更新日期：2026-07-27
原则：测试集保持锁定；所有阈值、标签模型和标准化参数仅由训练集产生。

## 1. 已确认的失败原因

| 原因 | 证据 | 处理 |
|---|---|---|
| 旧模型发生常数塌缩 | 最佳旧模型的 `prediction_delta_std_mm≈0.0002`，真实验证标签 SD 为 `0.1632`；风险概率 SD 约 `0.0003` | 删除训练初期的异方差 NLL；采用 Smooth-L1、CCC 和成对排序约束；第 5 轮设置预测方差熔断 |
| 年龄残差训练标签存在“训练内拟合更容易”问题 | 旧标签由同一个全训练模型同时拟合和预测训练样本 | 改为训练集 5 折 OOF 期望 CIMT；验证/测试仍仅由全训练集模型变换 |
| 左右眼解剖方向不一致 | 左眼视盘位于图像左侧，右眼视盘位于图像右侧 | 视野裁剪后统一水平镜像右眼；抽样亮视盘中心横坐标：左眼 0.297、标准化右眼 0.300 |
| 旧质量分数被背景支配 | 旧 `vessel_confidence≈0.92` 且 SD 极小 | 改为 7 项视野内指标：覆盖、清晰度、照明、血管密度、q95 信号、结构置信度、不确定像素率 |
| 导数血管场丢失密度和空间位置 | 旧 TubeField 仅保留方向导数，最终全局平均池化 | 将原始血管概率加入场通道，并使用 1×1、2×2、4×4 空间金字塔 |
| 只用血管概率图丢失颜色、病灶和全局纹理 | 纯血管场 5 轮训练损失近乎不降，并触发方差熔断 | 新增冻结、无标签 DINOv2 全局支路；先单眼融合全局与血管场，再做双眼共同/不对称融合 |
| 类别不平衡 | 训练加速风险阳性率 25.1%，验证 19.0% | BCE 使用仅由训练集计算的 `pos_weight`；风险与 Δ-CIMT 阈值增加一致性损失 |
| 重复年龄去混杂抑制有效信号 | 标签已经年龄/性别残差化，旧代码又在小批次内施加年龄协方差惩罚 | 删除噪声较大的 minibatch 年龄惩罚；年龄独立性改为报告指标而非重复优化 |
| 低质量眼底导致空分割 | 32 只眼血管 q95<0.5 且密度<0.05；人工检查最差图像确认严重模糊/曝光异常 | 显式 QC：单眼失败时权重归零、依赖对侧；双眼失败不进入训练；验证同时报告全队列与可判读队列及覆盖率 |
| 无早停且按分类指标保存回归模型 | 旧实验训练 35 轮，回归最优在第 1 轮而保存点按 AUROC 决定 | 回归按验证 MAE、分类按 AUROC 分别保存检查点；ReduceLROnPlateau + patience=8 |
| 官方验证队列存在分布漂移 | Δ-CIMT 均值：训练约 0，验证 −0.0568 mm；阳性率 25.1% vs 19.0% | 不对验证/测试重新居中；固定记录漂移，后续以开发集嵌套交叉验证估计稳定性，官方验证仅作独立开发外检查 |

## 2. 完整性与泄漏检查

- 患者数：2,903；左右眼图像：5,806。
- 分区：训练 2,603，验证 200，测试 100；患者交集为 0。
- 新缓存：`(2903, 2, 256, 256)`、float16、全部有限、无缺失。
- DINOv2 缓存：`(2903, 2, 384)`、float16、全部有限。
- OOF 训练标签阈值：训练 Δ-CIMT 第 75 百分位 `0.078396716 mm`。
- 质控覆盖率：验证集 199/200（99.5%）至少一眼可判读。
- 测试集未评估，未用于阈值、超参数或检查点选择。

## 3. 修复后的诊断结果（非正式结果）

5 轮反塌缩诊断中，最佳回归点在第 4 轮：

| 指标 | 仅临床期望模型 | 修复后混合模型 |
|---|---:|---:|
| 验证绝对 CIMT MAE | 0.1408 mm | 0.1348 mm |
| 验证绝对 CIMT R² | 0.3467 | 0.3997 |
| 验证 Δ-CIMT MAE | 0.1408 mm（零修正） | 0.1348 mm |
| Δ-CIMT 预测/真实 SD 比 | 0 | 0.0631 |

风险任务在第 2 轮达到 AUROC 0.5737、AUPRC 0.3527。该结果只说明程序已脱离完全常数解，不能作为最终论文性能结论。

## 4. 不能通过代码“消除”的限制

1. 官方验证集只有 200 人且与训练集存在队列漂移；正式结论必须增加开发集嵌套交叉验证和置信区间。
2. VascX 隔离运行时及动静脉、视盘、中央凹小样本推理已经验收；全 5,806 眼的断点批处理正在执行，完成前不得启动正式主实验。
3. 尚无独立的外部 Fundus-CIMT 配对队列；没有外部验证时不得声称跨中心泛化。
4. 单次 CIMT 测量的重复性/测量误差数据未提供；模型性能上限可能受到标签噪声限制。

因此，“代码已知缺陷修复完成”与“数据限制已解决”必须严格区分。正式主实验需等 VascX 全队列输出审计和嵌套交叉验证方案锁定后启动。
