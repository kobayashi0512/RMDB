# mBRSET 正规获取与 M0–M6 执行方案

## 结论

mBRSET 当前可通过 PhysioNet 的 credentialed access 合法获取。它不是开放直链数据，也不能通过 GitHub、Kaggle、网盘或作者仓库绕过访问控制。PhysioNet 要求每位使用者分别完成 credentialing、CITI Data or Specimens Only Research 培训并签署项目 DUA。

## 可执行步骤

1. 使用研究者本人邮箱注册并完成 PhysioNet profile credentialing。
2. 在 PhysioNet 指定的 CITI 页面选择 Data or Specimens Only Research。PhysioNet FAQ 说明，选择 Massachusetts Institute of Technology Affiliates 可免费完成该课程。
3. 将 CITI 结业记录提交到 PhysioNet，等待 credentialing 和培训记录审核。
4. 以个人身份签署 mBRSET 项目的 PhysioNet Credentialed Health Data Use Agreement。
5. 审核通过后，从 PhysioNet 项目页面下载 mBRSET 原始图像和 `labels_mbrset.csv`。如下载速度受限，仅使用 PhysioNet 页面提供的 AWS 或 GCP 选项，不使用第三方镜像。
6. 将数据放在本地受控目录，运行已冻结的 `run_reverse_m0_m6_cv.py`；禁止将原始图像、患者表或临床标签上传到 GitHub，也不能通过 API 或聊天服务发送。

## 重要限制

- 每名合作者都需要自己的 PhysioNet 访问权，不能共享账号或下载目录。
- GitHub 的 mBRSET 仓库是代码和说明仓库，不是数据授权替代品。
- PhysioNet 的 mBRSET embedding 项目同样标为 restricted access，不能作为无需审核的临床标签替代品。
- 如果无法完成个人 credentialing，论文只能保留 mBRSET 的既有内部探索性结果，不能声称独立外部临床确认。

## 数据到位后的固定运行顺序

1. SHA256 与患者数审计；
2. 图像、患者和结局表按 `patient` 连接；
3. 运行一次性 M0–M6 患者分组嵌套交叉验证；
4. 运行配对 bootstrap 5000 次；
5. 输出 AUROC、AUPRC、Brier、校准斜率、95% CI 和增量差异；
6. 保存原始 OOF、随机种子、配置和审计日志；
7. 不重新选择表型、不读取 CIMT 固定验证集或测试集。
