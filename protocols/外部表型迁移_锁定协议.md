# RMDB–BiRAP 外部表型迁移审计锁定协议

## 目的

在不读取任何固定 CIMT `val/test` 行、不使用临床结局调参的前提下，检验四个
结局盲可靠核心表型在不同眼底队列中的分布迁移程度，并形成可审计的失败域地图。
本实验属于**测量迁移与域偏移审计**，不属于独立临床终点确认。

## 固定队列

- 参考域：China-Fundus-CIMT 的 `split=train` 表型（5,206 眼，2,603 人）。
- 外部机制域：mBRSET；同一患者同一眼的重复视图先取中位数。
- 外部测量域：RAV、Fundus-AVSeg。

所有分析仅读取已冻结的 `per_eye.csv` 表型文件。不得读取 CIMT 原始 `val/test`
清单或标签，不得根据本实验结果改变表型定义。

## 固定表型

1. `soft_vessel_mass_fraction`
2. `mass_vessel_skeleton_length_density`
3. `factorized_vessel_skeleton_length_density`
4. `vessel_occupancy_disagreement`

## 固定分析

1. 以 CIMT-train 的中位数和 IQR 作参考尺度。
2. 报告外部域的稳健中位数偏移、IQR 归一化 Wasserstein 距离、KS 统计量和 PSI。
3. 对中位数偏移和 Wasserstein 距离进行 2,000 次患者级聚类 bootstrap。
4. 使用患者分组五折 OOF logistic regression 估计各外部域相对 CIMT-train 的
   域可分 AUROC；同时报告单表型和四表型联合结果。
5. 报告四表型 Spearman 相关结构相对参考域的平均绝对漂移。
6. 报告样本完整性、视盘检测率以及同眼重复视图聚合数量。

## 解释边界

- 域 AUROC 越高表示分布越容易区分，不代表疾病预测越好。
- 显著 KS 检验在大样本下可能只反映微小差异，主解释优先使用效应量和区间。
- RAV/Fundus-AVSeg 的像素标签可支持测量层解释，但没有 CIMT 结局，不能冒充
  外部临床验证。
- mBRSET 为 224 px 镜像和糖尿病人群，只作为外部机制与失败域证据。
