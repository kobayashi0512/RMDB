# 下一阶段：不确定性—方向—拓扑协同的 A/V 表型算法

## 目标

解决上一阶段暴露的核心瓶颈：A/V 密度比虽在五折中方向稳定，但其效应弱，
且当前分割伪标签没有独立外部校准。下一阶段不再增加通用视觉骨干，而是降低
血管表型的测量误差，并把分割不确定性显式传递到 CIMT 风险预测。

## 文献依据与可复用思想

1. Hu 等，Medical Image Analysis 2024，Hessian-based vector field：
   用局部 Hessian 方向场表征血管走向，在不同相机、对比度、分辨率、病灶和
   模态变化下提升血管分割域泛化。
   DOI: 10.1016/j.media.2024.103164
2. Morano 等，Expert Systems with Applications 2024，RRWNet：
   共享参数的递归修正网络逐轮纠正沿血管树传播的 A/V 类型错误。
   https://github.com/j-morano/rrwnet
3. Heng 等，ISBI 2024，Vascular Topology Rectification Network：
   使用持续同调修正血管连接性错误；提示拓扑约束应作用于结构纠错而非直接
   替代像素监督。
4. Muller 等，2023，Topology-Overlap Trade-Off：
   单纯增加拓扑损失可能改善连续性却加重 A/V 误分类；方向引导卷积可以缓解
   这一冲突。因此本项目采用“不确定性门控的拓扑损失”，不对交叉点和低置信
   像素强制同类连续。
5. Deng 等，Scientific Data 2025，Fundus-AVSeg：
   100 张全新临床图像，含正常、DR、AMD、青光眼和 17% 低质量图像，并提供
   五类像素标注，适合作为独立外部校准集。
   DOI: 10.1038/s41597-025-05381-2

## 拟实现模型：UDCT-AV

UDCT-AV（Uncertainty-guided Directional and Connectivity
Topology refinement for Artery/Vein segmentation）由四部分组成。

### 1. 基础概率场

冻结 VascX，输出背景、动脉、静脉、交叉四类 logits。保留软概率而不是只保存
argmax 标签，计算像素熵和多次扰动预测方差。

### 2. Hessian 方向场

从绿色通道/对比增强图像构建多尺度 Hessian 特征，获得血管切向量、管状度和
尺度。方向一致性损失只在管状度高的像素启用：

`L_dir = w(x) * ||∇_t p_A|| + w(x) * ||∇_t p_V||`

其目的不是把整条血管强制为同一类别，而是减少同一分支上的短距离标签跳变。

### 3. 递归拓扑修正器

轻量共享权重修正器重复三轮，每轮输入 RGB、基础概率、方向场、熵和上一轮
概率。修正器只学习残差 logits，避免小数据下重学完整分割：

`z_(k+1) = z_k + gθ(RGB, H, entropy, softmax(z_k))`

### 4. 不确定性门控拓扑与通道耦合

- 血管联合约束：`P(vessel) ≈ P(A ∪ V)`；
- 交叉点允许 A/V 同时存在；
- 未知区域不进入强监督；
- clDice/拓扑损失仅在高置信、非交叉区域启用；
- 低置信区域使用一致性训练而非伪硬标签。

这避免了文献所指出的“拓扑更连续但 A/V 分错更多”的问题。

## 训练和验证顺序

### 阶段 A：零样本外部审计

- RAV 206 张：用于设备/年龄/质量分层和流水线测试；由于其与 VascX 来源相关，
  不作为唯一独立外部证据。
- Fundus-AVSeg 100 张：主要独立校准集。
- LES-AV 或 HRF-AV：最终跨数据集验证。

输出：动脉/静脉 Dice、中心线 Dice、类型准确率、连接错误、A/V 比例误差、
ECE/Brier、低质量与不同设备分层结果。

### 阶段 B：修正器训练

- 固定基础模型；
- 训练 UDCT-AV 修正器；
- 消融：无方向场、无递归、无门控拓扑、无不确定性；
- 患者/图像级拆分，任何下游 CIMT 标签均不参与分割训练。

### 阶段 C：表型不确定性传播

对每张 CIMT 眼底图像进行概率抽样和形态扰动，得到：

- `E[A/V ratio]`；
- `Var[A/V ratio]`；
- 左右眼共同成分与不对称成分；
- 分割可靠性权重。

下游采用误差变量模型或精度加权层级模型：

`patient <- eye <- branch/pixel`

### 阶段 D：CIMT 重新评估

与上一阶段两特征 A/V 核心基线进行同一外层五折配对比较。主要成功标准：

1. A/V 比例在分割扰动下方向不变；
2. 五折残差 R² 全部为正；
3. AUROC/AUPRC 配对 bootstrap 置信区间至少一个不跨零；
4. 改善来自校准后表型，而不是年龄或成像设备捷径。

## 停止规则

如果独立数据上 A/V 类型准确率或比例误差不可接受，先解决分割域偏移，不进入
CIMT 训练。如果校准后 A/V 表型与 CIMT 的五折方向消失，则停止临床预测主张，
转为微血管表型测量学/关联研究。
