# mBRSET 低维、质控门控双读出表型探索协议

版本：2026-07-31  
状态：在运行本轮探索前锁定；**探索性**，不构成对既有 mBRSET 结果的独立确认。

## 1. 触发原因

全特征双读出模型在 mBRSET 患者级嵌套 CV 中未显示相对临床基线的增量，且包含约
150 个患者级派生变量。在 1,276 名高血压分析者中，这种维度与终点信息量的比例容易
放大分割噪声、视盘回退和多视图变异。因此本轮只检验一个更窄的问题：在不使用 Zone B
和不使用结局驱动特征筛选的前提下，少量全局表型是否有更好的稳健性。

## 2. 冻结的特征

仅使用双眼均值，且全部来自全局视野：

1. `soft_vessel_mass_fraction`：软血管质量；
2. `soft_av_log_mass_ratio`：软 A/V 质量平衡；
3. `mass_vessel_skeleton_length_density`：Mass-UDCT 血管长度密度；
4. `mass_vessel_branch_cluster_density`：Mass-UDCT 分叉密度；
5. `factorized_vessel_skeleton_length_density`：门控第二读出长度密度；
6. `factorized_av_log_area_ratio`：门控第二读出 A/V 平衡；
7. `vessel_occupancy_disagreement`：占据读出分歧；
8. `base_to_mass_identity_disagreement`：身份读出分歧；
9. `identity_entropy`：身份不确定性。

上述名单按测量含义预定义；不依据任何 mBRSET 终点单变量关联、AUROC 或模型系数作
增删。不包括 Zone B、视盘半径或有效像素数，以避免将 189 例视盘回退转换为伪生物学
信号。

## 3. 模型与比较

患者级五折外层、三折内层嵌套 CV；缺失填补、标准化和正则化选择均在外层训练折内。

- R0：年龄、性别、糖尿病病程；
- R1：R0 + 眼病分级/水肿；
- R2：R0 + 冻结低维血管表型；
- R3：R1 + 冻结低维血管表型。

主探索终点为系统性高血压；使用 5,000 次患者级配对 bootstrap。另在
`both_discs_detected=true` 的严格质控子集完整重复 R0–R3；该分析只检验质量门控的
稳健性，不能与全样本的绝对性能直接比较。

无 DR 高血压使用相同定义作敏感性分析。次要疾病终点不用于选特征或决定成败。

### 标签盲可靠性简化（唯一允许的后续迭代）

重复视图 ICC 审计在不读取疾病标签的条件下完成后，若特征 ICC(1,1) < 0.60，则其
测量稳定性不足，不保留在“可靠性简化”版本。mBRSET 的审计保留四项：软血管质量、
Mass-UDCT 血管骨架密度、门控第二读出血管骨架密度、血管占据分歧。该版本仅按此
标签盲阈值产生一次；之后不得再在 mBRSET 内依据任何结局表现调整特征。

## 4. 判读规则

只有当 R3 相对 R1 的 AUROC 改善、AUPRC 改善或 Brier 降低具有方向一致的 95% CI
支持，并且总体和严格质控分析不矛盾时，才可提出“值得在独立高分辨率队列确认”的
信号。否则结论仍是：当前双读出测量尚无可重复临床预测增量。
