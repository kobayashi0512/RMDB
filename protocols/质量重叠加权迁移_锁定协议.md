# RMDB–BiRAP 质量重叠加权迁移敏感性分析锁定协议

## 目的

解释外部表型迁移审计中观察到的分布漂移：检验在对齐可观测图像/测量质量后，
四个可靠核心表型的漂移是否仍然存在。本实验不使用任何疾病或 CIMT 结局，且只
读取 CIMT `split=train` 的冻结表型文件。

## 固定质量变量

- `disc_detected`
- `disc_radius_px`
- `zone_b_valid_pixels`
- `occupancy_entropy`
- `identity_entropy`
- `mean_gate`

这些变量在查看本实验结果前固定。不得加入四个主要表型本身，也不得加入年龄、
性别、疾病标签或 CIMT。

## 固定方法

1. mBRSET 同一患者同一眼的重复视图先取中位数。
2. 分别比较 mBRSET、RAV、Fundus-AVSeg 与 CIMT-train。
3. 用患者分组五折 OOF logistic regression 估计仅由质量变量预测的域倾向概率。
4. 使用 overlap weights：参考域权重为 `p(domain=external)`，外部域权重为
   `1-p(domain=external)`；权重天然有界，不进行结局驱动截断。
5. 报告质量变量加权前后的最大绝对标准化差、两域有效样本量和质量域 AUROC。
6. 报告四表型加权前后 IQR 归一化 Wasserstein 距离及相对衰减比例。
7. 使用固定 OOF 权重进行 2,000 次患者级聚类 bootstrap。

## 预设解释门槛

- `max |SMD| <= 0.10`：可观测质量达到可接受平衡；否则调整结果仅作失败诊断。
- 两域 overlap-weighted ESS 均不低于各自患者-眼数的 20%：认为存在最低可用重叠。
- 漂移衰减为正表示可观测质量解释了部分漂移；小于或等于零表示质量对齐没有解释
  该表型差异。

即便平衡成功且漂移衰减，本实验也不能区分设备、预处理和人群生物学因素，更不能
替代带患者级 CIMT 结局的独立高分辨率确认。
