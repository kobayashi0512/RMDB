# Three-layer evidence chain

Read-only synthesis of frozen artifacts. No CIMT fixed validation/test cohort was read or used for model selection.

1. **Phenotype accuracy:** AFIO/Mendeley outcome-blind annotation audit and frozen RMDB–BiRAP extraction; RAV/Fundus-AVSeg transfer scores.
2. **Cross-domain robustness:** FIVES and STARE frozen VascX migration, negative/weak scores retained; DRIVE is explicitly blocked by official access requirements.
3. **Clinical association:** BRSET/mBRSET patient-level exploratory CV and permutation negative control; not independent clinical validation.
