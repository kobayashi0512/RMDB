# RMDB-C / MESA 一次性外部验证锁定协议

状态：在获取或读取任何 MESA 患者级 CIMT 和原始眼底图像前起草  
主队列：MESA Exam 5  
开发队列：中国 Fundus-CIMT  

## 1. 冻结对象

在读取 MESA 原始图像前冻结并记录哈希：

1. 图像裁剪、左右眼镜像、颜色标准化和输入分辨率；
2. 血管占据、A/V 身份、视盘/黄斑定位模型；
3. 解剖坐标、Zone B、双眼共同/差异表型定义；
4. 特征列、缺失值处理和尺度变换；
5. H0 条件均值头和 H1 条件百分位稳健头；
6. 中国开发队列产生的参数、阈值和模型权重。

H2 融合仅探索性报告；双头分歧不作为不确定性。

## 2. 分析人群

主分析依次纳入：

1. Exam 5 有连续 CIMT；
2. 至少一眼 Field 1 原始图像；
3. 年龄和性别完整；
4. 图像能够通过预先冻结的自动 QC。

同时报告：

- 全部可链接样本；
- 双眼完整样本；
- 两眼 Field 1 均可分级样本；
- 自动 QC 通过样本。

自动 QC 失败样本不得静默删除，必须进入流程图和缺失机制比较。

## 3. 结局协调

### 3.1 严格绝对迁移

将 MESA CIMT 统一为毫米并映射到预先指定的共同颈动脉指标。直接应用中国队列
冻结的 H0/H1，禁止使用 MESA 结局更新预测头。报告：

- MAE、RMSE、R²；
- calibration-in-the-large 和校准斜率；
- Spearman 相关；
- H0 与 H1 的误差差异。

这是模型可移植性的最严格检验，但可能受不同超声扫描/读片协议的系统偏移影响。

### 3.2 协议差异稳健分析

为区分“超声口径偏移”和“视网膜信号失效”，在 MESA 内仅用年龄、性别和 CIMT
交叉拟合一个规范模型，构造外部 `Delta-CIMT`/条件百分位；任何眼底特征不得
进入该规范模型。冻结的 RMDB 影像分数用于检验：

- 与外部 `Delta-CIMT` 的相关和增量解释度；
- 条件百分位大于 0.75 的 AUROC/AUPRC；
- 相对年龄/性别基线的配对增量；
- 校准和决策曲线。

该分析验证跨协议的排序/偏离信息，不等同于绝对毫米预测。

## 4. 主要成功条件

不以单个点估计定成败。至少满足：

1. H1 对 accelerated CIMT 的 AUROC 95% CI 下界大于 0.5；
2. 影像表型相对年龄/性别基线的配对增量方向为正，且在主要亚组方向一致；
3. H0 的 R² 为正，或经预先声明的仅截距校准后校准误差明显下降；
4. 最坏性别/年龄/族群组性能没有灾难性崩溃；
5. 自动 QC 失败率和纳入选择不造成明显偏倚。

若绝对迁移失败但协议差异稳健分析成功，只能声称存在可迁移的排序/偏离信号，
不能声称可直接输出跨中心 CIMT 毫米值。

## 5. 统计与报告

- 95% CI：患者级 bootstrap 5000 次；
- 同一患者双眼始终作为一个聚类单位；
- 亚组：年龄、性别、族群、中心、图像质量；
- 缺失：完整病例为主，多重插补仅作敏感性分析；
- 预先生成纳入流程图、总体/亚组表、校准图、误差图和失败病例图；
- 不根据 MESA 结果新增特征、删除亚组或调整阈值。

## 6. 允许的校准边界

主结果完全不校准。若事先划出独立、患者级且不参与最终评估的校准子集，可附加：

- 仅截距校准；
- split conformal prediction interval。

不得在最终评估集上选择校准方式或区间宽度。若样本不足以同时保留校准集和
评估集，则不做 conformal 主张。
